# Archived development work

This directory contains inactive research and validation artifacts retained for
reference. Files here are not loaded, built, or shipped by the active R package.

- `portugal_idef/`: exploratory Portugal IDEF loader, build script, generated
  package inputs, and diagnostics.
- `france_ras_validation/`: figures and CSV diagnostics comparing French RAS
  inflation gaps.

Large restricted or raw survey ZIP archives remain under `data-raw/` and are
excluded explicitly in `.gitignore`; they are not part of this archive or of
the Git history.
